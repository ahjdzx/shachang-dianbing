# ui/
> L2 | Parent: ../../CLAUDE.md

界面层。覆盖在画布上的 DOM：外观，加一张开局牌。元素结构在 /index.html，回合流程和入座流程在 /src/main.js。
ui 不引用本项目的其他模块；要用的数据（阵型、难度）由 main 传进来。

## 成员清单

style.css: 设置面板、战况面板（双方、兵力表、棋谱）、胜率条、解说牌、终局横幅。界面是桌边的漆器小件：深漆底、金线描边、朱印点题；它退在棋盘后面，不抢色、不抢动。滑块、下拉框、滚动条、焦点环、选中色都按这套颜色重画，不留浏览器默认样式。屏宽不超过 700px 时换成手机布局：设置收成顶部一条（朱印、标题、战况、设置、暂停），战况变成底部抽屉，按钮加高到好点，四周让出安全区。

seating.js: 开局牌。人入座「点兵」时摆在桌边，只收集三个选择——执子、阵型、对手——并把变化通知 main；它用 localStorage 记住上次的选择。棋子怎么走位、对局怎么开始不归它管。

## 约定

- 桌上的三种状态写在 `body[data-mode]` 上：`demo` 电脑自己下、`muster` 点兵、`play` 人在下。零件的显隐一律由样式按它决定，main 只改这一个属性。
- 全场只有两处实心金：请人坐下的「我来下一盘」，和开局牌上的「开局」（终局后是「再来一盘」）。别的按钮不用实心金，暂停态也只用金框。
- 底部的入座按钮和解说牌同在 `.dock` 里，间距由容器定，不各自定位。
- 手机上的开局牌要在约 340px 内放完：真机可视高度远小于屏幕高度。「开局」一行钉在牌底。

- 颜色、间距、圆角、字体、缓动只在 `:root` 的定数里取值。新样式先找现成的定数，没有再加。
- 楷体（`--kai`）只给题字用：标题、朱印、棋谱、兵力表表头、横幅。正文和数字用黑体。
- 全场只有终局横幅有排场的进场动画，其余只做 0.2–0.35 秒的状态过渡；`prefers-reduced-motion` 下全部关掉。
- 断点三个：1100px 收窄两侧面板，900px 隐去战况面板，700px 换手机布局。设置面板在所有屏幕上默认收起。
- 兵力表的三种明暗：满编正常、有损 `.hurt`、打光 `.gone`；暗棋视角下认不出的兵种格是 `.unknown`。
- `.narrow-only` 的元素只在窄屏显示。
