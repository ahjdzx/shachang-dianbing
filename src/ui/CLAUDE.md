# ui/
> L2 | Parent: ../../CLAUDE.md

界面样式。只管覆盖在画布上的 DOM 外观，不含逻辑。元素结构在 /index.html，行为在 /src/main.js。

## 成员清单

style.css: 设置面板、战况面板（双方、兵力表、棋谱）、胜率条、解说牌、终局横幅。界面是桌边的漆器小件：深漆底、金线描边、朱印点题；它退在棋盘后面，不抢色、不抢动。滑块、下拉框、滚动条、焦点环、选中色都按这套颜色重画，不留浏览器默认样式。屏宽不超过 700px 时换成手机布局：设置收成顶部一条（朱印、标题、战况、设置、暂停），战况变成底部抽屉，按钮加高到好点，四周让出安全区。

## 约定

- 颜色、间距、圆角、字体、缓动只在 `:root` 的定数里取值。新样式先找现成的定数，没有再加。
- 楷体（`--kai`）只给题字用：标题、朱印、棋谱、兵力表表头、横幅。正文和数字用黑体。
- 全场只有终局横幅有排场的进场动画，其余只做 0.2–0.35 秒的状态过渡；`prefers-reduced-motion` 下全部关掉。
- 断点三个：1100px 收窄两侧面板，900px 隐去战况面板，700px 换手机布局。main.js 只认 700px 这一个，用同一个 matchMedia 决定设置面板默认收起。
- 兵力表的三种明暗：满编正常、有损 `.hurt`、打光 `.gone`；暗棋视角下认不出的兵种格是 `.unknown`。
- `.narrow-only` 的元素只在窄屏显示。
