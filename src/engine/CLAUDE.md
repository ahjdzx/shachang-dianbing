# engine/
> L2 | Parent: ../../CLAUDE.md

规则层，全项目的裁判。它不依赖任何模块，不产生随机数，可以在 Node 里单独运行。
它掌握全部真相。「谁能看见什么」不归它管，归 ai/knowledge。

## 成员清单

junqi.js: 军棋规则引擎。模块加载时从一小段描述生成棋盘拓扑（60 站、10 行营、4 大本营、32 个铁路站、133 条边），走法、路径、距离都查这份表。它裁定布阵是否合规、每个棋子能走到哪、交战谁胜谁负、对局何时结束。play() 返回的记录里带着全场都看得见的事实：经过的站、是否拐弯、因司令阵亡而亮出的军旗；暗棋推理和演出都只读这份记录。

## 约定

- 坐标：x 列 0..4，y 行 0..11；红方底线 y = 0。格子号 = y × 5 + x。
- 棋子编码：颜色 r/b + 兵种。兵种 9..1 是军衔（司令 9 … 工兵 1），B 炸弹，M 地雷，F 军旗。
- 布阵 layout 用己方视角（行 0 是底线）；黑方落盘时转 180°。
- STANDARD 是钉住 perft 的固定布阵。改它就要重算 EXPECT.opening 和测试里的 perft 值。
