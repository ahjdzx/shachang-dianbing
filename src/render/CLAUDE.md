# render/
> L2 | Parent: ../../CLAUDE.md

渲染层。它决定桌上的东西长什么样、镜头摆在哪。它只读对局，从不写对局。
依赖方向：render → engine。render 不引用 sim、ai、game。

## 成员清单

world.js: 场景地基。定义棋盘尺寸，提供「棋盘坐标 ↔ 世界坐标」的唯一换算 toWorld/fromWorld。它读引擎的拓扑表 STEP/RAIL/CAMP/HQ 画棋盘贴图，所以线路以规则为准，贴图不另存一份。它还搭桌子、灯光、两侧收子托盘和选子平面。托盘 3 列 × 9 行共 27 格，装得下一方全部 25 子，格子不复用。
figures.js: 棋子工厂。十二个兵种的造型只在这里定义。军官与士兵共用一副骨架，靠帽子、披风、肩章、武器区分军衔。背后的小旗所有兵种同一尺寸；setCloaked 把人偶换成军帐、旗和木块顶面换成「？」，蒙布后的棋子外形和待机动作完全相同（地雷、军旗、炸弹不蒙布时是不呼吸的死物，蒙布后照常呼吸）。几何体、材质、贴图全部走缓存，50 个棋子共用。
director.js: 自动导播。它读演出层给的 focus，在 24 个方位里求一个不出桌面、不被棋子挡的机位，用临界阻尼弹簧推拉。它支持自动、自由、俯视、入座四种模式；入座是己方身后的固定机位，给亲手下棋的人用；打开 muster 开关后换成点兵的构图，把己方半场让到开局牌旁边。爆炸时用 shake 抖镜头。它读相机的视野和宽高比：俯视的高度按画面算，竖屏时把自动机位沿视线拉远。它不知道规则，也不知道迷雾：给它什么焦点，它就拍什么。

## 约定

- 人偶的局部前方是 +Z。红方 root 转 180°，面向黑方。
- actor 的层次是 root → body → sway → figure / cloak / mast。出招和迈步动 body，呼吸和摇晃动 sway，蒙布切换 figure 与 cloak 的可见性。
- 木块顶面的字朝向棋子的主人，旗面的字由风向转到正对镜头；镜头俯角大时旗面再向后仰，俯视和竖屏入座时也读得到。
